# Kimi K2 / Kimi3 代码审查清单

## 审查优先级

### 1. 逻辑正确性（最高优先级）
- [ ] 任务分解是否合理，子任务是否完备
- [ ] 每个子任务的输入输出是否匹配
- [ ] 边界条件是否覆盖（空值、越界、类型不匹配）
- [ ] 执行顺序是否有依赖冲突

### 2. 长上下文一致性
- [ ] 跨文件引用是否正确（import 路径、类型导入）
- [ ] 修改是否与项目其他部分一致
- [ ] 是否遗漏了需要同步修改的文件
- [ ] 大型文档/代码库是否完整处理（无遗漏段落）

### 3. 代码质量
- [ ] 函数是否过大（超过 50 行考虑拆分）
- [ ] 命名是否清晰自解释
- [ ] 是否有重复代码可以提取
- [ ] 数据结构定义是否明确

### 4. 中文文档质量
- [ ] 注释是否清晰准确地描述功能
- [ ] 复杂逻辑是否有解释"为什么"
- [ ] 用户提示信息是否通顺自然
- [ ] 技术术语使用是否正确一致

### 5. 安全性
- [ ] 用户输入是否做校验和清理
- [ ] 敏感信息是否硬编码
- [ ] 权限检查是否正确
