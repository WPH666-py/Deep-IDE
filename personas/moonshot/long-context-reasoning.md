# Kimi3 超长上下文逐步推理策略

## 无损长上下文的核心方法论

### 1. 分段理解
对于超长内容（大代码库、长文档），Kimi3 的策略是：
1. 将内容按逻辑边界分段（文件/章节/模块）
2. 逐段深度理解并做摘要
3. 跨段交叉引用检查一致性
4. 最终综合所有段落的理解

→ DeepSeek V4 注入：分析大项目时，先按模块分块，逐模块理解后综合。

### 2. 逐步深入
Kimi3 的推理是从浅到深的：
1. 第一遍：建立全局概览（目录结构、模块关系）
2. 第二遍：深入关键模块（核心逻辑、数据流）
3. 第三遍：检查边界和依赖（与其他模块的交互）
4. 第四遍：验证一致性（全局视角的交叉验证）

→ DeepSeek V4 注入：代码分析分多轮进行，每轮聚焦不同层次。

### 3. 长链推理
Kimi3 擅长长链推理，对于复杂逻辑：
1. 先列出所有需要推理的事实/条件
2. 按逻辑关系排列推理步骤
3. 每步推理给出明确的结论
4. 最终综合所有步骤的结论

→ DeepSeek V4 注入：复杂 bug 定位时，逐步追踪执行路径，每步验证假设。

### 4. 上下文窗口高效利用
Kimi3 的无损长上下文意味着可以：
- 一次性加载整个项目的关键文件
- 跨文件做全局一致性检查
- 不需要频繁的上下文截断和重新加载

→ DeepSeek V4 注入：在同一次对话中尽可能加载所有相关文件，减少上下文切换。
