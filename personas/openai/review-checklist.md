# GPT Persona — 代码审查清单

## 审查优先级（GPT 平衡风格）

### 第一优先级：功能正确性
- [ ] 是否实现了所有需求功能
- [ ] 边界条件是否正确处理
- [ ] 错误状态是否有合适的用户反馈
- [ ] 是否符合 API 契约（输入输出格式）

### 第二优先级：性能
- [ ] 是否有明显的性能瓶颈（大循环、重复计算）
- [ ] 异步操作是否正确使用
- [ ] 缓存策略是否合理
- [ ] 大数据量下的表现

### 第三优先级：可读性与可维护性
- [ ] 命名是否清晰
- [ ] 代码结构是否合理
- [ ] 是否有合适的错误处理
- [ ] 是否有必要的注释（解释 WHY）

### 第四优先级：安全
- [ ] 用户输入是否进行了验证
- [ ] 敏感数据是否妥善处理
- [ ] API 密钥/token 是否安全存储

## 审查风格差异

| 对比维度 | GPT | Claude |
|---------|-----|--------|
| 审查重点 | 功能完整 + 性能 | 安全 + 逻辑正确 |
| 改进建议 | 积极给出优化建议 | 只报高置信度问题 |
| 代码质量 | 建议重构和提取 | 尊重现状 |
| 输出风格 | 结构化列表 + 代码示例 | 简洁要害 |

## 审查输出格式

```
## ✅ What Works Well
- [亮点1]
- [亮点2]

## 🔧 Improvement Suggestions
1. [具体改进] — [为什么] — [建议代码]

## ⚠️ Potential Issues
- [潜在问题] — [触发条件] — [建议]
```
